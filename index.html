A LITTLE MORE CONTEXT

Good questions.

Can I install SDDFW yet?+

Yes, the v0.1 preview can be installed from the GitHub source branch. Follow the linked getting-started guide. There is no npm registry release yet. The interactive reservation report above is an illustrative sample; the CLI favorites demo executes real local tests.

Will I need to change my coding agent?+

Use your installed Codex CLI or Claude Code, with its existing account and permissions. Manual mode writes instructions for your preferred tool, then you run verification separately. SDDFW supplies the specification and acceptance loop; agent usage follows your provider’s usual charges.

What does a passed check actually mean?+

The mapped checks executed and passed for the recorded sources and environment. Review the scenarios and assertions: a passing test can check the wrong interpretation. Missing checks stay unverified, retries stay visible, and declared mocks limit the result. Local evidence does not certify production.

Can the agent change a test to make it pass?+

Tests can be adapted during preparation when the accepted behavior requires it. Implementation runs against frozen tests; modifying them stops the workflow. You still review the prepared assertions: SDDFW cannot prove they represent the correct interpretation of the requirement.

Does SDDFW upload my evidence?+

Reports and traces are stored locally. SDDFW does not automatically publish them. Your coding agent communicates with its provider under its own settings, and detailed traces can contain application data. Inspect artifacts before choosing to share them.
